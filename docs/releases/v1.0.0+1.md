# HaizhuCode 1.0.0+1

HaizhuCode is a community fork of OpenCode Mobile that embeds the Haizhu
security-agent payload: a kernel prompt, specialized agents, skill packs and
an MCP registry, seeded into the phone's Linux environment on setup.

Change class: feature

## What changed for you

- **The app is HaizhuCode.** Package `io.github.haizhu.code`, its own name and
  icon identity everywhere the upstream named itself.
- **The Haizhu payload installs with setup.** The kernel
  (`universal-kernel-v31`), six agents (audit, blue, ctf, re, red, orchestrator),
  nine skill packs (APK analysis, binary exploitation, CTF solving, code audit,
  red/blue team, reverse engineering, security MCP, web pentest) and an MCP
  registry land under `/opt/haizhu` and are seeded into every agent home.
- **Custom API providers.** Providers that are not in the built-in catalog can
  be imported from the Providers page: an OpenAI- or Anthropic-compatible base
  URL, an optional API key, extra headers and a model list are written to the
  server's configuration, and the models appear in the picker. The `hz`
  command line inside the phone's Linux does the same (`hz provider`).
- **Everything upstream 2.1.1+59 shipped.** All upstream features and fixes
  through that release are included; upstream attribution and license remain.

## Notes

- The payload is installed by an app-side setup component, so removing the
  Haizhu component from setup reclaims exactly the files it wrote and leaves
  your own files alone.
- Debug builds are larger; use the release APK on a real phone.
