# v1.0.5+6 — DSHA theme port + new default look

Theme-port release: HaizhuCode adopts the DSHA client's visual
language (reverse-engineered from `dsh.android.client` resources and
bundled Web stylesheets) as its stock theme. The palette ships as a
built-in pack, so existing installs keep whatever they picked — only
the default changes.

## Ported palette

Extracted from the DSHA APK (`res/values*/colors.xml` + the embedded
`dsh-web-mobile` Material-3 tokens):

| Role | Dark | Light |
|---|---|---|
| Background | `#0F1219` near-black blue-gray | `#F2F6FB` cool paper |
| Surface | `#161B24` | `#FBFDFF` |
| Raised | `#1B212C` | `#FFFFFF` |
| Accent | `#5B8DEF` bright blue | `#3E6FD8` |
| Attention / danger | `#F07A7A` | `#D94F4F` |

The generated `_Spec` derives the full role set (text tiers, borders,
selection, link, code blocks) the same way the other bundled packs do.

## Changes

- New `ThemePackId.dsha` — generated pack, appears in the Appearance
  pickers as **DSHA**.
- `defaultThemePackId` is now `dsha` — first-run, reset-to-defaults,
  the overlay host, and Manage-space all agree on the new default.
- Appearance page: DSHA joins the featured row; the reset action now
  returns to `defaultThemePackId` instead of a hard-coded pack.
- Tests updated to assert the new default (palette values, guided-flow
  labels, preview state); explicit "pick Claude" coverage is kept.
