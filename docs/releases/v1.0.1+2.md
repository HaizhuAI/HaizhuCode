# HaizhuCode 1.0.1+2

Release infrastructure and documentation. Same app code as 1.0.0+1 —
this version makes every change a published release.

## What changed for you

- **Downloads now come from this repo.** The README and every link point at
  [HaizhuAI/HaizhuCode releases](https://github.com/HaizhuAI/HaizhuCode/releases);
  the APK attached here is the signed sideload build.
- **One change = one release.** Each change lands as its own `v<x.y.z+N>`
  tag with a signed `HaizhuCode-release.apk` on the release — the
  [`latest` page](https://github.com/HaizhuAI/HaizhuCode/releases/latest)
  always carries the newest build. Process: `docs/releasing.md`.
- **The README is about HaizhuCode**, in English and 简体中文: the payload,
  security agents, skill packs, providers, assistants, and the real
  sideload signer fingerprint are all documented.

## Upgrading

Installs over 1.0.0+1 in place — same signing lineage
(`24:CE:74:B6:…:A9:1C:6D:19`). Settings, servers and on-phone projects are
kept.
