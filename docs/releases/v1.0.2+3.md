# HaizhuCode 1.0.2+3 — 2026-11-10

Bug-fix release: custom provider / assistant configuration could not be
saved on a real OpenCode 2 server.

- Fixed: **custom API import failed to save** — the write used
  `PATCH /experimental/config`, which accepts `{shell}` alone
  (`Config.Patch`, `additionalProperties: false`) and answered 400 on
  every provider/agent body. Provider, assistant, and default-model
  writes now go through `POST /api/experimental/fs/write` — the server
  config document is read (`/api/fs/read` with the config directory as
  the location), merged, and written back, and the running instance
  hot-reloads it. Verified end-to-end against `@opencode/cli` 2.1.1.
- Fixed: configured assistants never listed — `/config` `info` is the
  normalized shape (`agents`, model as `{providerID, model}`, `system`,
  `request.body` sampling, `disabled`), not the raw `agent` map.
- Changed: assistant preset read-back accepts both the normalized and
  the raw entry shape; removal also clears a stale `model` pointer.
- Docs: protocol notes updated for the fs/write config path.
