# v1.0.3+4 — Pinky phone control over MCP

Feature release: agents can now drive a real phone (Android or iPhone)
through [Pinky](https://github.com/DIYgod/pinky), the desktop gateway that
exposes `phone_*` tools over MCP.

## What's new

- **`pinky` MCP registry entry** (`haizhu/mcp/registry.json`) — remote HTTP
  transport template `{HZ_PINKY_URL|http://127.0.0.1:7465/mcp}` with
  `Authorization: Bearer {HZ_PINKY_TOKEN|}` header templating.
- **`hz phone <url> [token]`** — one command pairs a running Pinky gateway:
  writes the registry entry (literal URL + bearer header, enabled) and runs
  `hz mcp sync` so opencode.json, `mcpServers` (claude/gemini) and codex TOML
  all get the server at once. `hz phone` shows pairing state;
  `hz phone off` disconnects.
- **MCP sync now carries `headers`** — http-transport registry entries may
  declare a `headers` map; values go through the same `{VAR|default}` env
  expansion as URLs. Synced into OC2 (`type:"remote"` + `headers`),
  claude/gemini (`type:"http"` + `headers`) and codex
  (`[mcp_servers.<id>] url + http_headers`).
- **Disabled entries are actually removed** — `hz mcp disable` / `hz phone
  off` now delete the server from synced configs (oc2 `mcp.servers`,
  `mcpServers`, codex `[mcp_servers.*]` sections). Previously sync only ever
  added entries, so a "disconnected" phone stayed reachable.
- **Skill pack `phone-ops`** — distilled Pinky agent guide: connect / act /
  release loop, screen-refs vs OCR coordinates, the status codes
  (`approval_pending` → re-send with `approval_id`), the approval model
  (payments always ask; Pinky's gateway enforces it, not the agent),
  credentials/OTP rules, file push-pull, app install + logs, device toggles,
  and `hz phone` setup instructions.

## Usage

1. Run Pinky on a PC and enable Remote agents
   (`pinky daemon --http 0.0.0.0:7465`); grab the token (`pinkyctl token`).
2. In the managed environment: `hz phone http://<PC-LAN-IP>:7465/mcp <token>`.
3. Ask the agent to do something on the phone — the person watches in
   Pinky's window and approves risky steps (payments always require a tap).

The app's Integrations page can also add the server by hand:
`type = remote`, `url = http://<pc>:7465/mcp`,
`headers = { "Authorization": "Bearer <token>" }`.

## Verification

- `hz phone` lifecycle end-to-end on a fixture config tree: pair writes
  `{type:"remote", url, enabled, headers}` into oc2 `mcp.servers`, `http`
  + headers into claude `mcpServers`, `url` + `http_headers` into codex
  TOML; `off` removes the entry from every target (grep count 0).
- `sh -n` syntax clean; registry JSON validates; bundle regenerated
  (70 files).
